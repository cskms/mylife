MyLife (내생활관리) 개인정보처리방침

시행일: 2026년 10월 16일

1. 처리하는 정보

  • 사용자가 직접 입력한 차량 정보, 정비 이력, 주행거리, 거래 내역, 분류, 메모
  • 사용자가 선택한 카드·은행 앱의 알림 내용 (금액, 가맹점, 일시 등). 사용자가 휴대폰 설정에서 알림 접근을 허용한 경우에만 읽습니다.
  • Google Drive 연결 시 사용자 Google 계정의 이메일 주소 (연결 상태 표시용)

2. 이용 목적

차량 정비 시기 알림, 가계부 자동 작성, 지출 리포트, 정기결제 알림 기능을 제공하기 위해서만 사용합니다.

3. 저장 위치와 보관

  • 모든 데이터는 사용자의 휴대폰에 저장됩니다.
  • 사용자가 Google Drive 연결을 선택하면, 사용자 본인의 Google Drive 에 "내생활관리" 폴더를 만들어 백업 파일과 구글 시트를 저장합니다.
  • 앱은 Google Drive 에서 앱이 직접 만든 파일에만 접근합니다 (drive.file 권한). 사용자의 다른 파일은 읽거나 수정하지 않습니다.
  • 개발자가 운영하는 서버는 없으며, 데이터를 개발자나 제3자에게 전송·판매·공유하지 않습니다.

4. Google 사용자 데이터

MyLife 가 Google API 로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 포함하여 해당 정책을 따릅니다.

5. 삭제

  • 앱을 삭제하면 휴대폰의 데이터가 삭제됩니다.
  • Google Drive 의 "내생활관리" 폴더를 삭제하면 백업이 삭제됩니다.
  • Google 계정 설정 › 보안 › 타사 앱 액세스에서 MyLife 의 권한을 언제든 철회할 수 있습니다.
